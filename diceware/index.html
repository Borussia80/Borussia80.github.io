Como funciona

Por que é seguro

Cada palavra é sorteada com o gerador aleatório criptográfico do navegador (crypto.getRandomValues()), com todas as palavras igualmente prováveis. A senha é gerada no seu aparelho e não é enviada a nenhum servidor. O que torna a senha forte é o número de palavras: com a lista completa, 6 palavras já passam de 77 bits; o padrão de 7 dá cerca de 90 bits.

Como os dados funcionam

Cada palavra corresponde a uma combinação de dados: 5 dados por palavra com a lista selecionada. As faces são lidas como um número na base 6, que aponta a palavra na lista. As listas embutidas têm exatamente 6⁵ = 7.776 ou 6⁴ = 1.296 palavras, então toda rolagem vale. Numa lista personalizada de outro tamanho, as rolagens que caem fora da lista são refeitas (0% nesta lista), o que mantém o sorteio justo.

Cuidado com a tela

Quem vir os dados e conhecer a lista consegue reconstruir a senha. Evite gerar senhas com a tela compartilhada, gravada ou à vista de outras pessoas, ou ligue o modo discreto em Opções.

Sobre as listas

A lista completa (7.776 palavras) e a curta (1.296 palavras, 4–7 letras) foram geradas por um processo reproduzível: só palavras sem acento, nenhum par que difira por uma única letra, nenhuma palavra que seja o começo de outra e remoção de termos ofensivos. São auditadas (estrutural) + curadoria semântica por proxy automático: a revisão de conteúdo foi feita por modelos de IA, não por falante nativo. A lista curta tem critérios próprios e não é parte da completa. Detalhes em AUDITORIA-LISTAS.md.

Números da lista selecionada

Lista com N palavras, ou N bits por palavra. Para chegar a ~77 bits, use pelo menos N palavras. A última senha gerada tem 0 bits. Maiúscula, número e símbolo exigidos por sites não contam como ganho de força.
